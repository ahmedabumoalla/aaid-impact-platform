# عائد — الواجهة الأولى

نموذج واجهة عربية RTL لمنصة عائد، مبني بـ React وTypeScript وMotion.

## التشغيل

```bash
npm install
npm run dev
```

## التحقق

```bash
npm test
npm run build
```

الأرقام الاستثمارية داخل النموذج مستخرجة من العرض المرجعي وموسومة كأرقام مستهدفة/تقديرية، وليست ضمانًا للعائد.
